② API Routes（Next.js App Router）
方法 路径 功能 认证 说明
POST /api/generate 生成旅行攻略 可选 调用 Gemini + YouTube，返回 SSE 流式响应
POST /api/itineraries 保存攻略 需登录 将生成结果持久化到 Supabase
GET /api/itineraries 获取历史列表 需登录 返回当前用户最近 10 条攻略摘要
GET /api/itineraries/[id] 获取攻略详情 需登录 返回完整 content JSONB，含视频和预算
DELETE /api/itineraries/[id] 删除攻略 需登录 RLS 保障只能删自己的数据
GET /api/youtube 搜索 YouTube 视频 内部 封装 YouTube Data API v3，返回标题+缩略图+链接
