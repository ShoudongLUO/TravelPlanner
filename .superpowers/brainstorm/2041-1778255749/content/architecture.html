系统整体架构

旅游攻略系统 — Next.js + Supabase + Gemini + YouTube API

用户层 (Browser)
🗺️ 目的地 / 时间 / 预算 输入表单
📄 完整攻略文档展示
📚 历史攻略记录
🔗 小红书 / YouTube 跳转链接
⬆⬇
Next.js App（Vercel 免费托管）
🎨 React UI 页面
📡 API Routes（/api/generate、/api/history）
🔐 NextAuth.js（Google/GitHub OAuth）
⬆⬇
Gemini API（免费）
gemini-1.5-flash
生成完整攻略文档
行程 + 预算 + 贴士
Streaming 输出
YouTube Data API v3（免费）
搜索目的地相关视频
返回标题 / 缩略图 / 链接
嵌入攻略文档中
小红书（无 API）
自动构造搜索 URL
如：小红书搜"京都3天"
以卡片形式展示链接
⬆⬇
Supabase（免费层）
🗄️ PostgreSQL — 存储用户攻略
🔐 Auth — Google/GitHub 登录
📋 RLS 行级权限控制
核心数据流
用户填写表单 → API Route 并行调用 Gemini + YouTube API → 合并结果 → Streaming 输出到前端 → 用户登录后保存至 Supabase → 下次访问可查历史
