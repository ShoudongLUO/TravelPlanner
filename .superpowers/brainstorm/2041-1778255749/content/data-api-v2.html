② API Routes（含新增反馈接口）
方法路径功能认证说明
POST /api/generate 生成攻略 可选 Gemini + YouTube 并行，SSE 流式响应；注入同目的地历史反馈作为 prompt 上下文
POST /api/itineraries 保存攻略 需登录 生成完成后持久化到 Supabase
GET /api/itineraries 历史列表 需登录 返回最近 10 条，含 review 状态（已反馈/待反馈）
GET /api/itineraries/[id] 攻略详情 需登录 返回完整攻略 + 关联 review（如有）
DELETE /api/itineraries/[id] 删除攻略 需登录 级联删除关联 review
POST /api/itineraries/[id]/review 提交反馈 NEW 需登录 评分 + 实际花费 + 亮点 + 改进建议，一条攻略只能提交一次
PATCH /api/itineraries/[id]/review 修改反馈 NEW 需登录 允许用户在旅行后补充或修正反馈内容
GET /api/youtube YouTube 搜索 内部 封装 YouTube Data API v3

💡 Prompt 注入策略：生成新攻略前，查询当前用户同目的地的历史 reviews（最多 3 条），提取 highlights 和 improvements 字段，拼入 Gemini system prompt：
"根据该用户的历史反馈：{highlights}，以及改进建议：{improvements}，优化本次行程推荐。"
无历史反馈时，Gemini 按通用逻辑生成，不影响首次体验。
